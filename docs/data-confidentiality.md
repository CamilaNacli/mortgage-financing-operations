# Data Confidentiality

My work involves highly sensitive information: identification documents, proof of income, financial details and other personal data. Protecting this information is a core professional responsibility, not an afterthought.

## How I handle client information in my day-to-day work

- **Documents stay out of the tracker.** The tracking spreadsheet records the status and key dates of each application. Client documents are never attached to it.
- **One folder per client and application.** Documents are organized in Google Drive in separate folders, so each case is kept apart.
- **Access is limited to authorized people.** Documents are only shared with those who need them to process the application.
- **Only what is needed.** I collect the information and documents required for the application, guided by my intake checklist.

## How this public repository was prepared

This repository is a **demonstration**. It reproduces the structure and logic of my real system using fictional data only.
